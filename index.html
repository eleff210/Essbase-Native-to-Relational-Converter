Turn an Essbase export
into clean columns.

Upload your ASO Level0 backup file and your dimension metadata extracts. This converts the native, quote-delimited Essbase export into a flat, relational file — one row per real value, correctly paired with its period — plus a run log. Nothing is uploaded to a server; the file never leaves this tab.
